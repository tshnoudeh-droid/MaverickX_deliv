# MaverickX — TKS Deliverable

Immersive website deliverable for the MaverickX TKS challenge. Built by Tawfic Shnoudeh and Armaan Sharma.

Replaces a slide deck / Notion doc: the reviewer (Suman) scrolls through an experience that presents our research and proposes our solution (germanium extraction).

## Stack

- Next.js 16 (App Router, TypeScript, Tailwind v4)
- shadcn/ui (`components/ui/`)
- Framer Motion for scroll-driven animation

## Status

Early scaffold. Content is placeholder throughout. Two hero prototypes live at `/demo/tunnel` and `/demo/sculpture` — pulled from 21st.dev as starting points to pick a visual direction before building the real hero with MaverickX branding.

## Dev

```bash
npm install
```
